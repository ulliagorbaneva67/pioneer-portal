# ПИОНЕР. Внутренний портал

Локальный корпоративный портал на Flask и SQLite.

## Возможности

- задачи с исполнителями, наблюдателями, приоритетами и двойным согласованием;
- сотрудники, роли, права и статусы присутствия;
- автоматические подмены на период отсутствия;
- новости, уведомления и локальные чаты;
- календарь, встречи, помещения и бронирования;
- аналитика, недельные отчёты и CSV-экспорт.

## Запуск на Windows

1. Установите Python 3 с сайта <https://www.python.org/downloads/>.
2. Запустите `ЗАПУСТИТЬ_ПИОНЕР.bat`.
3. Откройте <http://127.0.0.1:5000>.

При первом запуске автоматически создаются `.venv` и база `pioneer.db`.

## Важно

Рабочая база, фотографии, документы и резервные копии исключены из Git намеренно:
они могут содержать персональные и корпоративные данные. Для локального запуска
положите собственные `pioneer.db` и файлы в `uploads/` рядом с кодом.

## GitHub Pages

GitHub Pages публикует только статические HTML/CSS/JavaScript-файлы. Flask,
SQLite и серверные маршруты на Pages не запускаются. В каталоге `docs/` находится
статическая страница-презентация проекта, которую можно опубликовать через Pages.
Сам портал запускается локально или на хостинге с поддержкой Python.
