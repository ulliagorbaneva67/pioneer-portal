ПИОНЕР. Внутренний портал

Локальный корпоративный портал для задач, сотрудников, согласований, календаря, коммуникаций и аналитики.

Исходный код находится в этом репозитории

Задачи

Исполнители, наблюдатели, приоритеты, дедлайны и двойное согласование.

Команда

Карточки сотрудников, роли, права, статусы и автоматические подмены.

Рабочий день

Новости, сообщения, календарь, встречи, помещения и бронирования.

Контроль

Аналитика отделов, недельные отчёты, уведомления и экспорт в CSV.

Демонстрационная статическая страница GitHub Pages. Полный Flask-портал запускается локально через ЗАПУСТИТЬ_ПИОНЕР.bat.
